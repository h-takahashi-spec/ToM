# 解説（教員用・公開しない）

## 正解：アイスのレモン味

| 種類 | 味 |
|---|---|
| アイス | ソーダ／**レモン** |
| クッキー | レモン／抹茶／メロン |
| グミ | いちご／キャラメル |
| チョコ | ソーダ／抹茶／キャラメル |

ミナトは「種類」、ハルは「味」を知っています。

### ① ミナト「わからない。でも、ハルさんもわからないってことは、わかってる」
- **メロン**と**いちご**は、リストに1個しかない味です。もし正解がこのどちらかなら、ハルは最初から答えがわかります。
- ミナトは「ハルがわからない」と**断言**しています。これは、ミナトが教えられた種類の中に、メロンやいちごが**一つもない**ということです。
- したがって**クッキーとグミは、種類ごと候補から外れます**。
- 残る候補：アイス（ソーダ・レモン）、チョコ（ソーダ・抹茶・キャラメル）

### ② ハル「最初はわからなかったけど、今わかった」
- 残った5個の中でソーダは2個あるので、ソーダだったらハルはまだ決められません。
- ハルが「わかった」と言ったので、ソーダは外れます。
- 残る候補：アイス・レモン、チョコ・抹茶、チョコ・キャラメル

### ③ ミナト「それなら、私もわかった」
- チョコだったら、抹茶とキャラメルの2つが残っていて、ミナトは決められません。
- ミナトにわかったのだから、種類はアイスです。答えは**アイスのレモン味**です。

## つまずきやすい点（Q3・Q4 で見えるもの）

- **①を「選ばれたお菓子が、ありふれた味である」とだけ読む**
  メロンといちごの2個だけを外して、8個を残してしまうタイプです（Q3 で8個前後を選んだ人）。
  この読み方で進むと、②の時点で、ハルが特定できる味が一つもなくなり、詰まります。Q5 の自由記述で「矛盾した」「わからなくなった」と書く人は、多くがこのタイプのはずです。
  ここでの問題は、「ミナトは、自分が知っている情報（種類）の範囲で、ハルのあらゆる可能性を見渡したうえで断言している」という、**相手の知識状態を相手の側から**組み立てる操作が落ちていることです。
- **レモンを①の時点で消してしまう**
  クッキーを外すときに、クッキーにもある「レモン」までまとめて消してしまう誤りです。
  候補（お菓子そのもの）を消すことと、属性（味）を消すことを混同しています。
- **③を飛ばして「チョコ・抹茶」などを選ぶ**
  ハルが「わかった」と言った時点で考えるのをやめてしまうタイプです。
  ハルが答えにたどり着いたことで、ミナトの知識状態も更新される、という最後の一段を追えていません。

## 心の理論の講義へのつなげ方

- **何次の推論か**
  - ①：ミナトは「ハルが知らない」ことを知っている（**二次**の知識）。
  - 解く側は、そのミナトの視点にさらに立つ必要があります。「ミナトが、ハルの知識について何を知っているか」を学生が推論するので、**三次**の入れ子です。
  - ②・③では、「相手の発言を聞いて相手の知識がどう更新されたか」を追う必要があり、時間方向にも入れ子が深くなります。
- **サリー・アン課題との対比**
  サリー・アン課題は「サリーの頭の中のビー玉の位置」を一つ表象すれば解けます。それに対し、このパズルでは、**自分がまだ答えを知らない状態**で、他者がとりうる知識状態を**すべて**列挙する必要があります。
  大人がこけるのは、誤信念を理解する能力がないからではありません。入れ子の深さと、並行して保持する可能性の数が、作業記憶と実行機能の容量を超えるからです（cf. Kinderman, Dunbar & Bentall, 1998；Apperly らの「信念推論はコストのかかる処理」という議論）。
- **知識の呪い**
  解説を聞いた後で「なんでこんなのがわからなかったんだろう」と感じたら、それ自体が知識の呪いの実演になります（Birch & Bloom, 2007）。解説の前後で「何%の人が解けたと思うか」を予想させると、解説後の予想が上振れする様子を見せられます。
- **データの見せ方の例**
  - Q1 正答率と平均の自信度を並べて、自信のずれ（過信）を見せる。
  - Q3 → Q4 → Q1 の順に正答率がどこで落ちるかを示し、「どの段の他者視点で落ちたか」を見せる。
  - 原題を見たことがある人（seen_before）とない人の差を比べる。
